# GreenRoute V7

## Project Overview
GreenRoute V7 is a comprehensive Route Optimization application featuring a dual-solver architecture (Classical OR-Tools and Quantum algorithms) designed to minimize distances, reduce fuel consumption, and lower CO2 emissions for fleet routing.

## Features
- **Dual Solvers:** Compare routes generated by Classical (OR-Tools) vs Quantum approaches.
- **Emission Tracking:** Calculates fuel consumption and CO2 emissions for generated routes.
- **Interactive Map UI:** Visualizes fleet routes, depot locations, and customer stops.
- **Fleet Management:** Configurable vehicle capacities and types.
- **Analytics:** Benchmark performance between different solvers.

## Tech Stack
- **Backend:** Python, FastAPI, OR-Tools, NumPy (QUBO / BQPhy quantum-inspired solver)
- **Frontend:** React, Node.js (Vite/Next.js)
- **Testing:** Pytest

## Installation

### Backend Setup
1. Navigate to the backend directory: `cd backend`
2. Create a virtual environment: `python -m venv venv`
3. Activate the virtual environment:
   - Windows: `venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`

### Frontend Setup
1. Navigate to the frontend directory: `cd frontend`
2. Install dependencies: `npm install`

## Running the Project

### Start the Backend
```bash
cd backend
uvicorn app.main:app --reload
```
The API will be available at `http://localhost:8000`

### Start the Frontend
```bash
cd frontend
npm run dev
```
The frontend will be available at `http://localhost:3000` (or the port specified by Vite/Next).

## Running Tests
To run the backend test suite:
```bash
cd backend
pytest
```

## CSV Format
The application expects uploaded dataset CSVs to have the following columns (example):
`Customer_ID, Latitude, Longitude, Demand`

Example row: `1,12.9716,77.5946,10.0`

## Known Limitations
- Quantum solver (BQPhy) handles up to 50 customers directly; larger datasets are split into clusters of ≤8 customers and solved per-cluster.
- Real-time traffic data is not yet integrated.
